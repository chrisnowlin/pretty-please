END-TO-END FLOW (With PowerPoint Support)
===========================================

1. User uploads presentation.pptx
   ↓
2. API validation:
   file_ext = ".pptx"
   if ".pptx" in SUPPORTED_FORMATS:  ✓ TRUE
   → ACCEPTED
   ↓
3. Task processing:
   is_image = file_ext in IMAGE_FORMATS  ✗ FALSE
   → Text processing path (not vision)
   ↓
4. DocumentProcessor.load_document():
   call loader_factory.load(presentation.pptx)
   ↓
5. LoaderFactory.get_loader():
   for loader in [Text, Markdown, Image, PDF, Docx, PowerPoint]:
       if loader.supports(".pptx"):  ✓ PowerPointLoader.supports() = True
       → return PowerPointLoader instance
   ↓
6. PowerPointLoader.load(presentation.pptx):
   - Open presentation with python-pptx
   - Extract text from all slides
   - Track slide boundaries
   - Extract metadata
   - Return Document object
   ↓
7. Document object created:
   {
     "content": "Slide 1 Title\nSlide 1 Text\n\nSlide 2 Title\n...",
     "metadata": {
       "format": "pptx",
       "slide_count": 10,
       "author": "John Doe",
       "title": "Q4 Report",
       "slide_boundaries": [
         {"slide_number": 1, "start_index": 0, "end_index": 234},
         {"slide_number": 2, "start_index": 236, "end_index": 512},
         ...
       ]
     },
     "source": "/path/to/presentation.pptx"
   }
   ↓
8. DocumentProcessor.chunk_document():
   chunks = chunking_strategy.chunk(document)
   (FixedSizeChunker, SentenceChunker, or SlidingWindowChunker)
   ↓
9. For each chunk, generate embedding:
   embedder.encode_text(chunk.content, task="retrieval")
   ↓
10. Store in vector database:
    vector_store.add_embeddings(
      collection_name=collection,
      embeddings=[...],
      documents=[chunk_content, ...],
      metadatas=[chunk_metadata, ...]
    )
    ↓
11. SUCCESS ✓
    PowerPoint fully indexed and searchable

ARCHITECTURAL STRENGTH: Format-Agnosticism
==========================================

Why adding any new format is simple:

Pipeline Layer          Format-Aware?   Why
─────────────────────────────────────────────────────────────────
File Upload             YES             File validation (necessary)
Loader Factory          YES             File extension dispatch
LoaderFactory.load()    YES             Creates appropriate loader
DocumentLoader subclass YES             Specific format handling
Document creation       NO              Abstract "content + metadata"
Chunking                NO              Just text processing
Embeddings              NO              Just numerical vectors
Vector Storage          NO              Generic embedding storage
Search                  NO              Generic vector similarity
RAG Generation          NO              Generic text + embedding use
