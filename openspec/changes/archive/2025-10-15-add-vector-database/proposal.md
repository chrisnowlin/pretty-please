## Why
Enable persistent storage and efficient similarity search for embeddings generated by the Jina model. Local vector database is essential for building the retrieval component of the RAG pipeline.

## What Changes
- Integrate ChromaDB for local vector storage (with LanceDB as fallback option)
- Implement collection management for different document types
- Add CRUD operations for embeddings and metadata
- Support similarity search with configurable metrics

## Impact
- Affected specs: storage (new)
- Affected code: New storage module, integration with embeddings module
- Blocks: Document ingestion and query interface features
- Depends on: Core Jina embeddings implementation
